# Карта engine2: провинции трёх сценариев (шаг E1b) — план

**Статус: план, 2026-10-27, к решению владельца.** Поручение владельца 2026-10-27: карта и провинции
— на отдельной сессии Claude («картограф»), **для всех трёх сценариев**, не только для milan.
Агент engine2 (E3, затем (д)) карту не трогает; картограф не трогает `engine2/src` и чужие тесты.
Работа — в отдельной копии репозитория, ветки `engine2/map-*`, мерж — по команде владельца.

Бриф: §2a («данные карты — новые», «десятки провинций на сценарий, а не сотни»), §8 строка E1b
(«граф провинций связен; каждая провинция у одного владельца; старая карта не тронута»).

## 1. Что есть сейчас (замер по `main` 760d136)

  (`public/geodata/<сценарий>/<актор>.geojson`, ~200 байт: Милан — коробка 8,5–10,5° в. д. ×

  1477 годов.
- **Старая карта не меняется** (бриф §2a, AGENTS §11): `public/geodata/**` и `src/scenarios/*/map.toml`
  этот шаг не трогает.

## 2. Что провинция должна нести (схема engine2, `ProvinceData`)

`name`, `owner`, `area_km2`, `land` (закрытый перечень: `Arable`, `Hills`, `Steppe`, `Desert`),
`coastal`, `population`, `neighbours`, `sea_neighbours`, `governor`, `culture`, `religion`; плюс
`regions` — именованные множества провинций (цель «объединить»).

**Раздел труда:**

| поле | кто | как |
|---|---|---|
| полигон, `name`, `area_km2` | карта (E1b) | площадь вычисляется из полигона |
| `land` | карта | выводится из рельефа и климата (§4) |
| `coastal`, `neighbours`, `sea_neighbours` | карта | выводятся из геометрии (§4) |
| `owner` на дату старта | карта | по источникам, одна держава на провинцию |
| `culture`, `religion` большинства | карта | по источникам, грубые группы (вопрос 2) |
| `regions` | карта | исторические области по источникам |
| `population`, акторы, дома, люди, наместники, устремления, отношения, институты | данные сценария (E4 / E7) | вопрос 3 |

## 3. Принцип: одна основа — три раскладки

- **Строительные блоки** — современные административные единицы второго уровня (ADM2), обрезанные по
  береговой линии. Историческая провинция — объединение блоков. Границы точны до блока; где блок
  режет историческую границу, это записывается как приближение.
- **Раскладка сценария** — таблица «блок → провинция → владелец на дату старта», у каждой строки
  источник (правило E0: без источника строки нет; «по памяти» — помечается).
- **Один конвейер** для трёх раскладок: блоки общие, правила вывода (§4) общие, различаются только
  таблицы раскладки и охват.

## 4. Правила вывода (параметры инструмента, не движка; каждое записано)

- **Площадь** — по полигону в равновеликой проекции (EPSG:6933), без округления до блока.
- **Соседи по суше** — полигоны с общей границей не короче `L_min` (касание углом — не соседство).
- **Прибрежность** — граница провинции идёт по береговой линии.
- **Соседи по морю** — морские зоны по IHO (Лигурийское, Тирренское, Адриатическое, Ионическое,
  Эгейское, Мраморное, Чёрное…; крупные — делятся): две прибрежные провинции — соседи по морю, если их
  берега выходят в одну зону. Переход по морю — тик, как по суше (правило движения engine2). Каждый
  массив суши (остров, колония) связан с главным графом.
- **Тип земли** из закрытого перечня: `Hills` — если на изрезанный рельеф приходится не меньше
  половины площади (ETOPO 2022); `Desert` / `Steppe` — по климату (Кёппен BW / BS); иначе `Arable`.
  Открытый вопрос E4 «орошаемая долина» (Нил, Паданская равнина): карта **помечает** такие провинции
  отдельным свойством геоданных; тип земли в движке не меняется, пока владелец не решит.
- **Владелец** — по источнику на дату старта; где провинция в источнике поделена — у кого большая
  часть площади, с записью.

## 5. Источники (лицензии позволяют хранить производные данные в репозитории)

- **Геометрия:** Natural Earth 10m — суша, береговая линия, реки (общественное достояние);
  geoBoundaries ADM1/ADM2 (CC BY 4.0, с указанием авторства); Marine Regions, IHO Sea Areas
  (CC BY 4.0); NOAA ETOPO 2022 — рельеф (общественное достояние); климат Кёппена — Beck et al. 2018
  (CC BY 4.0).
- **Исторические границы:** Shepherd W. R., *Historical Atlas* (1911/1923; общественное достояние) —
  «Italy about 1494», карты Византии и Османов XV века, «Roman Empire about 395» с диоцезами;
  Droysen G., *Allgemeiner historischer Handatlas* (1886; общественное достояние); списки провинций
  — *Laterculus Veronensis*, *Notitia Dignitatum* (тексты). Современные защищённые атласы
  (Barrington и др.) — только для сверки, не для обводки.
- Файл `ATTRIBUTION` с указанием авторства для данных CC BY.

## 6. Конвейер и файлы

- `tools/map/` — скрипт на Python (shapely, pyproj; версии закреплены), детерминированный: один
  вход — тот же выход побайтово. Исходные данные скачиваются в кэш вне репозитория, в репозитории —
  их список с контрольными суммами.
- **Выход на сценарий:**
  - `public/geodata2/<сценарий>/provinces.geojson` — упрощённые полигоны для интерфейса (E5),
    свойства: `id`, `name`, `owner`, `region`;
  - таблица провинций в именах полей схемы engine2 (`area_km2`, `land`, `coastal`, `neighbours`,
    `sea_neighbours`, `owner`, `culture`, `religion`, `regions`) — данные сценария на E4/E7
    добавляют к ней население и остальное;
  - превью для владельца — картинка или страница с провинциями и владельцами.
- Подложка для 1430/1477 (не DARE) — решение на E5; карта даёт векторную основу.

## 7. Приёмка (на каждый сценарий)

- граф по суше и морю связен; каждый массив суши достижим;
- у каждой провинции ровно один владелец; у каждого актора сценария с землёй — хотя бы одна
  провинция; внешние силы без земли — перечислены;
- соседство симметрично; морские соседи только у прибрежных (это же проверяет компиляция engine2);
- сумма площадей совпадает с площадью суши охвата (±2 %);
- распределение типов земли печатается и сверяется глазами (в Италии нет `Desert`/`Steppe`);
- компиляция через схему engine2 — в тесте, с заглушкой населения (половина выведенной ёмкости,
  только в тесте; настоящее население — E4/E7);
- превью принято владельцем;
- `public/geodata/**` и `src/scenarios/*/map.toml` не тронуты.

## 9. Вопросы владельцу

1. **Охват milan_1477:** включать ли венецианское заморье (Истрия–Далмация, Корфу, порты Мореи, Крит)
   и балканский берег Османов как несколько крупных провинций? Рекомендация — да, крупно: без них
   война Венеции с Османами и Отранто идут «из-за края карты».
2. **Культура — насколько дробно:** грубые языковые группы (итальянская, окситанская и французская,
   немецкая, греческая, южнославянская, албанская, тюркская, арабская; для 375 — латинская и
   греческая половины империи и т. д.) или итальянские диалектные области (ломбардская, венецианская,
   тосканская…). Отчуждение по языку питает распад: диалектное дробление сделает «чужими» пол-Италии.
   Рекомендация — грубые группы, а местную принадлежность несут регионы.
3. **Население и остальные данные сценариев (E4 / E7)** — делает картограф вслед за картой или агент
   engine2?
4. **Источники по §5** (общественное достояние и CC BY с указанием авторства) — согласны?

### 9a. Решения владельца (2026-10-27)
