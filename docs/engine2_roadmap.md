## 3. Роли и процесс

| кто | делает | не делает |
|---|---|---|
| **Владелец** | решения по вопросам плана; команда на мерж | — |
| **Рецензент** (отдельная сессия) | планы с решениями до кода; рецензия кода; независимый перемер чисел своим прогоном; этот файл | код движка |
| **Исполнитель** (отдельная сессия) | код, тесты, замер, свой раздел плана «сделано» | решения за владельца; подбор чисел (§24.1) |
| **Картограф** (отдельная сессия) | данные карты, `engine2_map.md`, тесты карты | код движка |

**Правила, которые держат процесс:**

1. Каждое изменение — черновой PR. Мерж — только по прямой команде владельца.
2. План до кода. Стоп без подбора (§24.1): при стоп-условии — числа, разбор и кандидаты, но
   ни одного подобранного числа.
3. Числа исполнителя рецензент перемеряет сам: отдельный worktree и свой `CARGO_TARGET_DIR`.
   Общий target однажды дал ложное равенство.
4. В конец `engine2_e1_plan.md` пишет один участник за раз. Свой раздел исполнитель пишет
   после мержа плана рецензента.
5. `src-tauri/` вне воркспейса: менять его можно только с явной причиной, а каждый изменённый
   файл добавлять в коммит по имени (AGENTS.md).

## 4. Что можно вести параллельно

**Главное ограничение.** Пока идёт шаг, который меняет поведение ботов или правила мира
(`engine2/src/agents.rs`, `worth.rs`, `economy.rs`, `army.rs`, `diplomacy.rs`, `params.toml`,
`tests/agents.rs`), второй такой шаг вести нельзя. Каждый замер идёт против прошлого main: два
изменения сразу смешают и эффект, и базу, и не будет видно, что сдвинуло меру. Эта линия —
строго одна.

**Параллельно с ней можно** — в своей ветке от свежего main и своих файлах, не трогая файлы
линии выше:

| работа | кто | файлы | условие |
|---|---|---|---|
| План следующего шага, если он не зависит от замера текущего: например, уточнение (д2) | рецензент | раздел плана | в план — после мержа раздела исполнителя (правило 4) |
| Источники для кандидата 6 §30.13: двор, Э9, А11 на войне, А3 | отдельная сессия-исследователь или рецензент | `docs/` | только документ; числа в `params.toml` — отдельным шагом линии |
| Список «на E4» по карте: чума, доля холмов | картограф | `public/geodata2/`, `engine2_map.md` | правка схемы движка — только шагом линии и через владельца |
| Тексты milan для E4: перечитать `llm_context`, где он пересказывает историю после старта; общее правило в `forbidden_claims` | отдельная сессия | данные сценария, тексты | схема E4 ещё не утверждена, поэтому это черновик |
| Подготовка E5: выбор движка по сценарию в `src-tauri`, модель представления из `WorldView` | отдельная сессия, **по решению владельца** (бриф ставит E5 после E4) | `src-tauri/`, `src/` | только через публичный контракт `Simulation`; engine2 не править |
| Время тестов: тест агентов 274 с, 200 сидов — 300–380 с | — | `tests/agents.rs` — файл линии | **нельзя сейчас:** конфликт с исполнителем; только между шагами |

**Как не мешать друг другу:**

- одна сессия — одна ветка — свой набор файлов; пересечение по файлам — не параллельно;
- у каждой сессии свой `CARGO_TARGET_DIR`;
- параллельная работа не меняет базу замера: `params.toml` и правила мира — только линия;
- старый движок (`src/`, `src-tauri/` вне E5) — только то, что мешает играть (бриф §10).
