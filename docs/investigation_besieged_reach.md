# Висячие ссылки на мёртвых соседей и радиус `besieged`: `(C)` — предикат не менять

**Статус:** стадия 1 выполнена, **вердикт `(C)` — правки нет**. Ворота не пройдены по измерению, не по отсутствию дешёвой правки.
**Эталон:** `main` = `3a39497` (после PR #49). Пробник `src/bin/siege_probe.rs`, 3 сценария × 30 сидов (`0…29`) × 300 тиков без игрока; самопроверка **0 расхождений на 240 гибелях**.
**Постановка:** `investigation_successor_edges.md` §7.2 п.2, §8: актор, у которого все соседи на расстоянии 1 погибли без наследника, не осаждаем ⇒ бессмертен по пути `conquest`; кандидат — читать `besieged` на `d ≤ 2`.

## 1. Метод

`check_collapses` требует для пути 3 (`conquest`): `mil < 0.01 ∧ leg < 10 ∧ ep > 85 ∧ besieged`, где `besieged` = вооружённый живой актор на `d = 1` **в собственном списке** гибнущего. Пробник на каждом тике для каждого живого актора (и для погибшего на этом тике — по финальным метрикам и последнему списку) считает пять чтений `besieged` и повторяет счётчик «три опасных тика подряд» под каждым:

| вариант | чтение |
|---|---|
| `own1` | как в движке — контроль: обязан воспроизвести каждую реальную гибель тик-в-тик (**воспроизвёл 240/240**) |
| `own2` | собственный список, `d ≤ 2` — **кандидат постановки** |
| `sym1` | `d = 1` в **любом** из двух списков (ребро — граница, кто бы её ни записал) |
| `sym2` | `d ≤ 2` в любом из двух |
| `heir` | «границу мёртвого без наследника берёт осаждающий»: сильнейший вооружённый сосед `d1` наследует рёбра погибшего, и все, кто перечислял погибшего, теперь перечисляют его |

Контрфакт первого порядка (метод задачи 23): вариант говорит, **на каком тике актор погиб бы**, но после первой контрфактной гибели мир расходится, поэтому считаются только первые гибели каждого актора. Известное слепое пятно: пара, гибнущая на одном тике, — для второго сосед уже удалён.

## 4. Почему — граф расстояния 1 почти пуст по контенту

Пар `d = 1` в авторских списках (обход `create_*`, без учёта спавнов):

| сценарий | акторов | пар `d = 1` |
|---|---|---|
| rome_375 | 15 (+7 шаблонов) | **2** (`armenia–sassanids`, `huns–ostrogoths`) |
| constantinople_1430 | 9 | **1** (`byzantium–ottomans`) |
| milan_1477 | 13 | 12 |

Это воспроизводит задачу 10 («conquest ограничен почти пустым графом расстояния 1: rome 2 пары на 22 актора»). Отсюда всё остальное: `sym1` не меняет ничего в rome/constantinople, потому что и с другой стороны ребра `d1` нет; `heir` не меняет ничего, потому что у погибшего нет других рёбер `d1`, которые можно было бы передать; `own2` меняет **всё**, потому что `d = 2` — это и есть рабочий радиус авторской географии, и читать его в `besieged` значит снять клапан: результат совпадает с тем, что PR #23 измерил для «дешёвого предиката без осады» (12 акторов rome и оба протагониста гибнут 20/20) — здесь протагонист milan гибнет в 15 из 16 живых партий.

Единственный содержательный флип `sym1` — `savoy` ← `france`: спавн Франции (задача 3) перечисляет Савойю на `d1`, обратной записи нет. Это не висячая ссылка, а одностороннее ребро спавна — другой объект.

## 5. Развилка и вердикт

| | вариант | измерено | вердикт |
|---|---|---|---|
| (A) | `own2` / `sym2` — `d ≤ 2` | снимает клапан целиком: +6 акторов rome 30/30, +4 constantinople 30/30, протагонист milan 15/16 | **отклонён** — тот же класс, что «дешёвый предикат» PR #23 |
| (B) | `sym1` — симметричное чтение `d1` | 0 в rome/constantinople; в milan только `france → savoy` | не решает объект; как отдельная гигиена рёбер спавна — за скобками |
| (E) | «границу берёт осаждающий» | 0 в rome/constantinople, 1–2 в milan | не решает объект: передавать нечего |
| **(C)** | **предикат не менять** | — | **принят**: «недостижимый — не завоёвываемый» когерентно; дефект не в предикате, а в **контенте** — граф `d1` в rome/constantinople почти пуст, и это авторское решение о том, кто с кем граничит |

Что означало бы «починить» по-настоящему: дописать рёбра `d = 1` в rome (Дунай `rome–visigoths`, Рейн `rome–alamanni`/`franks`, Африка `rome–vandals`…) и в constantinople. Цена измерена приближённо строкой `own2`: каждый варвар, получивший вооружённого соседа `d1`, становится смертным (30/30), и половина безыгрокового мира rome перестаёт быть бессмертной. Это решение сценариста, с собственным равновесным расчётом (бой, миграция, релевантность идут по тем же парам), не правило движка.

## 6. За скобками

- **Контент: граф `d = 1` в rome и constantinople — ✅ РЕШЕНО ВЛАДЕЛЬЦЕМ И ВНЕСЕНО** (лимес Рима + османы–Сербия, [`investigation_d1_graph.md`](investigation_d1_graph.md) §9). Было — 2 и 1 пара. Кандидат на задачу сценариста, не движка; цена — строка `own2` §3.
- **Одностороннее ребро спавна** (`france → savoy`): `sym1` даёт Франции возможность завоевать Савойю в 9 партиях. Правило задачи 3 «одной стороны достаточно» — для пар; для `besieged` нет. Тот же класс, что закрыла `(D₄)` для наследников перенацеливанием; для спавнов — открыт.
- **Треть мира — беззащитные бессмертные** (§2): `leg 0`, `ep 100`, `mil 0`, жив. Это свойство предикатов гибели и производителей давления (задачи 27/28), не осады.
- Слепое пятно пробника: пара, гибнущая на одном тике.
