**Статус:** стадия 1 выполнена (обход + измерение 2×2), **правок движка нет**; развилка §6, критерий стадии 2 §7.
**Эталон:** `main` = `c564795`. Свидетельство — ветка `investigate/combat-loss-model` (`bac71b5`, **NOT FOR MERGE**): переключатели `E13_LOSS_MODEL` / `E13_REGEN` в `interactions.rs`. При пустом окружении выход побайтово равен `main` (проверено: `sim` rome/const сид 42; `siege_probe` три сценария сид 0 — эталонный бинарник пересобран из `c564795`).
**Постановка:** `investigation_split_as_shrink.md` §6: потеря как доля **своей** армии независимо от противника делает крупную державу самой уязвимой к множеству слабых соседей; Рим после PR #54 разоружён к тику 31 в 30/30 партий.

## 1. Обход: кто вообще пишет `military_size`

Перепись **по типу получателя** (правило §5.G), два пространства порознь.

**Движок — ровно один писатель:** `calculate_military_interaction` (`interactions.rs:497,501`), и он **обеим сторонам только вычитает**. Больше ни один движковый сайт `military_size` не трогает.

**Контент — по сценариям:**

| | rome_375 | constantinople_1430 | milan_1477 |
|---|---|---|---|
| `auto_delta` (структурный приток) | **`base = −0.2`** (у `rome`; отток) | **`+0.5`** у `ottomans`, `0.0` у `byzantium` | **нет ни одного** |
| зависимость `external_pressure → military_size` | есть, `mode = excess`, порог 50, коэфф. 0.01 — **вычитает** | есть, та же | есть, та же |
| `actions.toml` (действия игрока) | 1 сайт | 5 сайтов (`byzantium`: +5.0/+4.0/+6.0 → **+5.5/тик** при 3 действиях) | 2 сайта |
| случайные события | 3 | 3 | 4 |

**Следствие, выведенное, а не измеренное.** `external_pressure` у почти всех акторов насыщается на 100 (задачи 27/28), значит зависимость снимает **`(100−50) × 0.01 = 0.5` армии за тик у каждого актора, постоянно**. Структурный приток есть **у одного актора во всём проекте** (`ottomans`, `+0.5/тик`) — ровно столько, чтобы компенсировать этот отток, и ни у кого больше. Всё остальное поступление — действия игрока, то есть только у протагониста и только пока игрок их тратит.

`military_size` — **сток без источника**: тот же класс, что `population`/`economic_output` задач 20–22 (там он был закрыт добавлением пропорционального источника, коэффициент выведен, а не подобран).

## 2. Механизм: две независимые половины

1. **Форма потерь.** `attacker_loss = 5…15 %`, `defender_loss = 15…30 %` — **доли собственной армии**, не зависящие от противника (`interactions.rs:452–453`). Рим (350) против аламаннов (28): Рим платит 17…52, аламанны 4…8. Пять фронтов лимеса дают ~60 боёв за партию, и держава с армией 350 проигрывает войну на истощение пяти племенам суммарной численностью 150.
2. **Отсутствие источника** (§1). Проигранная армия не возвращается никогда; каждый бой — храповик вниз для обеих сторон.

Ни одна половина сама по себе не даёт наблюдаемого: при форме (1) с источником армия восстанавливается между боями; при отсутствии источника, но пропорциональных потерях, сильный не разоружается.

## 3. Измерение: 2×2 (30 сидов × 300 тиков без игрока; ратифицированные ворота — `sim scripted`)

Оси: **форма потерь** — `v0` (как есть) / `v1` (доля масштабирована соотношением сил) / `v2` (размен: каждый теряет долю армии **противника**); **источник** — нет / `E13_REGEN` (восстановление к стартовому значению на долю дефицита за тик).

| вариант | армия Рима t50 / t290 | «беззащитные бессмертные» rome | гибели варваров лимеса (из 30) | rome balanced ×3 | **const balanced ×5** |

| **`v0`, без источника (`main`)** | **2 / 2** | **26.8 %** | 15…17 | ✅ 3/3 (31/31/34) | ✅ **5/5** (119/76/91/107/99) |

Прочее: const `ottomans` t290 263 → 285 (`regen 0.01`) / 219 (`regen 0.03`); milan — армия протагониста t290 5 → 29, «беззащитных» 10.8 % → 3.2 %, гибели `milan` 9/30 → 0/10; rome `wealth` 0/3 во всех вариантах (как на `main`).

## 4. Главная находка: ратифицированные ворота constantinople стоят на этом дефекте

Победа constantinople — `ottomans.military_size < 40`, выбранная **редизайном PR #14** именно потому, что была достижима. Достижима она ровно потому, что нынешняя форма потерь позволяет малой армии с притоком (`byzantium` +5.5/тик от действий игрока) перемолоть большую (180) в ноль: у османов приток +0.5/тик, и размен долями своей армии работает против того, у кого армия больше.

**Как только форма потерь исправлена — любым из двух способов, с источником или без — османы сохраняют армию (283…292 к тику 290), и победа не наступает ни в одной из пяти ратифицированных партий.** Это не регрессия правки, а обнаружение зависимости: условие победы было откалибровано поверх дефекта.

Поэтому форма потерь **не может быть изменена отдельно** от пересмотра условия победы constantinople — а это ратифицированное решение (PR #14), и его пересмотр требует собственной стадии 1.

## 5. Соотношение с прежними выводами (не противоречит им)

- Задача 5/16: «асимметрия потерь — ускоритель, не корень» — верно и подтверждается здесь: `v1`/`v2` **не** спасают Византию (она гибнет 30/30 без игрока во всех вариантах) и не меняют, кто побеждает в rome по семейной победе. Новое здесь — не про Византию, а про **rome после PR #54**: пять фронтов превращают ускоритель в основной механизм разоружения протагониста.
- Задача 6: «рычаг нельзя настроить, он лишь переворачивает, кого уничтожают» — воспроизводится на новой оси: `v1`/`v2` переворачивают rome (варвары 15…17/30 → **30/30 каждый**). Ось источника ведёт себя иначе: `regen 0.03` даёт **разброс** (1…10 из 10 по акторам), а не переворот.
- Задача 17: вариант «потери пропорционально сопротивлению» был назван и оставлен нереализованным — здесь он измерен (`v1`) и отклоняется не по вкусу, а по §4.

**Оговорка к (B), обязательная.** Мой пробник восстанавливал армию **к авторскому стартовому значению сценария** — это чтение шаблона, ровно тот класс дефекта, который закрыл PR #47 (`split_metrics_for_successor` читал шаблон вместо состояния). Это **измерительный прокси для проверки класса, а не предлагаемая конструкция.** Кандидаты в источник, каждый со своим равновесным расчётом (стадия 1 задачи (B)):
- **(B₁)** пропорционально `population` (людской ресурс) — у rome 8000, у аламаннов 400: даёт крупной державе восстановление, соразмерное её размеру;
- **(B₂)** пропорционально `economic_output` / `treasury` (вербовка и содержание) — связывает армию с экономикой, уже есть зависимость `military_size → economic_output`, появится встречная;
- **(B₃)** контентом: `auto_delta` на `military_size` в каждом сценарии — без правки движка, но 3 сценария × N акторов авторских чисел, и milan сейчас не имеет ни одного;
- **(B₄)** к авторскому старту — **отклонён как конструкция** (чтение шаблона), оставлен только как прокси §3.

**Рекомендация: (B), подвариант выбирается её собственной стадией 1** по образцу задачи 22 (коэффициент выводится из измеренных величин, не подбирается свипом). (A₁)/(A₂) — не начинать до пересмотра условия победы constantinople.
