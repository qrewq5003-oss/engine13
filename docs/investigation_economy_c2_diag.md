# Проект экономики, Ц2 и население — диагностика на нынешнем мире (без изменения движка)

Решение владельца после Ц3 (2026-10-08): с Ц2 стадии 3 (PR #220) мир сильно изменился — Ц5–Ц9 и Ц3 убрали каскад,
вассалы перестали воевать, у сплочения и легитимности есть нормы. Прежние числа Ц2 не годятся; сначала замер. Мир — v2
как в контенте (Ц1, Ц3–Ц9), все 10 миров, сиды 0–29 и 100–129, 300 тиков. Зонд — `src/bin/c2d_probe.rs`
(`--features census`), режим `debtors` — разложение казны должников.

**Итог.**
- **Долг:** исправленное предрешение не проходит ни при одном x (5 / 10 / 20 %) ни в одном мире; пункт (4) — гибели
  ключевых не растут — держится везде. Должников стало больше, чем на стадии 3: в долге все народы rome, вассалы Ц7
  (89–95 % их жизни), Сербия, Трапезунд, папство, малые дворы milan. Класс один — **армия дороже дохода** (содержание в
  1,05–9,5 раза больше дохода без правила; исключение — Валахия, у неё доход чуть выше); дань — не причина (0–119 за партию). Замёрзший долг: гунны, саксы, Урбино
  по-прежнему без населения; Сицилия больше не зомби.
- **Накопление:** казна монотонно растёт к тику 150 у Сасанидов, Гуптов, Восточной Цзинь (rome, 30 из 30 игр, 28–66 тыс.),
  Османов (30 из 30, 35–52 тыс.) и Венгрии (21–27 из 30, ~4 тыс.); в milan — ни у кого. Доход у них в 2,2–3,3 раза больше
  содержания, прочие записи — ±100. **Набор войска бесплатен** (восстановление только проверяет платёжеспособность) — и
  этим богатым почти нечего набирать: +10…+160 армии за 150 тиков, они стоят у ёмкости.
- **Население:** обезлюдения Рима больше нет (8 000 → ~3 615 при расколе, дальше ровно 3 600–3 680; у ≤ 1 — 0 игр).
  Зомби остались: народы rome — 13–14 % живых актор-тиков (саксы — во всех играх), малые дворы milan — 19–20 % (Мантуя,
  Урбино во всех играх), constantinople — 4,5–6 % (Валахия, Трапезунд). Главный писатель-темп —
  `economic_output_to_population`; при притяжении к норме с r = 0,01 он держит население на 21–33 % нормы при среднем
  своём темпе и на 10–19 % — при p90.

## 1. Долг — исправленное предрешение (§9.7)

(1) во всех мирах p90 периода долга ≤ 12 тиков без тиков зомби; (2) в мирах без игрока никто не в долге > 20 % учтённых
тиков; (3) в сыгранных — доля печатается; (4) гибели ключевых (Рим, Византия, Османы, Милан) парно не растут, t < 3.

### Таблица b/r для «население тянется к авторской норме», r = 0,01

При притяжении `P += r × (N − P)` и темпе убыли ρ × P равновесие — P* / N = r / (r + ρ). Измеренные темпы (события —
разовые, не темп; миграция — `interactions.rs` ≈ 1081, вынос 1 % населения источника):

| сценарий | писатель | действует, доля живых актор-тиков | ρ средний / p90 | P*/N при среднем / при p90 |
|---|---|---|---|---|
| rome | `economic_output_to_population` | 9,8–10,0 % | 0,035 / 0,084–0,086 | 22 % / 10–11 % |
| rome | `low_economic_output_to_population_decay` | 0,9–1,0 % | 0,091 / 0,157–0,159 | 10 % / 6 % |
| constantinople | `economic_output_to_population` | 4,4–4,9 % | 0,036–0,037 / 0,075–0,078 | 21–22 % / 11–12 % |
| constantinople | `low_…_decay` | 0,3 % | 0,069–0,070 / 0,136–0,138 | 13 % / 7 % |
| milan | `economic_output_to_population` | 5,2–5,4 % | 0,020 / 0,043–0,046 | 33 % / 18–19 % |
| все | миграция (источник) | 0,3–1,9 % | 0,010 | 50 % |

**`economic_output_to_population` (deficit_proportional) — где сдвиг наибольший.** Темп пропорционален населению:
ρ(eo) = 0,125 × (1 − eo / θ₁) + 0,1875 × (1 − eo / θ₂)⁺, θ₁ = 50 × T / 100, θ₂ = 15 × T / 100 (T — норма экономики
актора, Ц1 стадия 3). Наибольший при eo = 0: ρ = 0,3125, P*/N = 3 %. При eo = θ₁ / 2 — ρ = 0,0625, P*/N = 14 %. Темп равен
r уже при дефиците 8 % порога (eo = 0,92 θ₁): **любой дефицит экономики больше 8 % порога вдвое и сильнее опускает
равновесие населения ниже нормы** — при r = 0,01 правило по построению побеждает притяжение.

**Миграция при притяжении к норме.** Объём мал: 45–113 человек за игру на сценарий (0,2–2,8 % стартового населения),
действует на 0,3–1,9 % живых актор-тиков. С притяжением источник отрастёт к норме, получатель сойдёт к своей — поток
станет обратимым, но по объёму это почти ничего не меняет. Для постоянного источника (держава под давлением > 65 и
сплочением < 40) — равновесие 50 % нормы.
