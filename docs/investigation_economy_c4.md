# Проект экономики, Ц4 стадия 1: бой с исходом

Решение владельца после Ц3/Ц4 стадии 0: смерть-завоевание будет читать исход войны (Ц7), а для этого у боя нужен
победитель (Ц4). Зонд — `src/bin/c4_probe.rs` (`--features census`), 30 сидов × 300 тиков, все 10 миров. База — v2
как в контенте (`e84341c`).

**Итог: мерило Ц4 у (а) не пройдено — 54,8 % при пороге 60 %. В контент ничего не вписано.** Стоп-правило не
срабатывало: Ц1, Ц5 и Ц6 у (а) держатся. Разбор неудачи — в §2: сама формула на боях мира обещает стороне с лучшим
качеством около 58 %.

## Что построено (v2, переключатель `economy_v2_combat_outcome`, в контенте `false`)

Кто нападает и как часто, не тронуто: бросок, кулдаун 5 тиков, тики 0–2. Меняется только исход
(`interactions::resolve_battle`).
- **Сила стороны:** `S = армия × качество / 100`.
- **Победитель:** нападающий выигрывает, если бросок исхода меньше `S_a / (S_a + S_d)` (половина, если обе силы нулевые).
- **Потери:** проигравший — 15–30 % армии и 10–20 сплочения (давление — только без модели угрозы); победитель —
  5–15 % × min(1, S_проигравшего / S_победителя).
- **Порядок случайных чисел:** бросок исхода тянется из того же потока сразу после броска нападения и до четырёх
  прежних бросков потерь. Прежние броски берутся по ролям: 5–15 % — потеря победителя до масштаба, 15–30 % — потеря
  проигравшего, затем сплочение и давление проигравшего. С выключенным переключателем броска исхода нет, поток прежний.
- **Протокол боя** (`census::Battle`, только с фичей `census`): стороны, армии и качества до боя, силы, победитель,
  потери.
- **Варианты для замера** — переключатели census: (б) `set_combat_quality(false)` — сила без качества; (в)
  `set_combat_loss_scaled(false)` — потери победителя без масштаба.

**Тесты в обе стороны:**
- `economy_v2_battle_outcome_reads_strength`: на равномерной сетке бросков при равных армиях качество 80 против 40
  выигрывает 2 из 3; если поменять качества местами — 1 из 3; при равных качествах решает численность; без качества
  равные армии — поровну; масштаб потерь победителя 5/80; без масштаба — 1.
- `economy_v2_battle_loser_takes_the_losses`: с исходом потери 15–30 % и сплочение берёт проигравший, кем бы он ни был,
  а победитель — масштабированные 5–15 %; без исхода — всегда защитник.

**Побайтовость:** с выключенным переключателем мир v2 тот же, что на `e84341c` (300 прогонов `drift_probe` с
`ECONOMY_V2=1`); с выключенным v2 — тот же, что v1 (300 прогонов, `sim` 10 из 10).

## 2. Разбор неудачи: что обещает сама формула

Для каждого засчитанного боя — вероятность, которую формула (а) `S = армия × качество / 100` даёт стороне с лучшим
качеством, и сколько та выиграла на деле.

| разрыв в качестве | боёв (а) | выиграно (а) | обещает формула | выиграно (б) |
|---|---|---|---|---|
| 10–20 | 185 | 49,2 % | 54,6 % | 49,3 % |
| 20–30 | 72 | 68,1 % | 58,9 % | 43,3 % |
| ≥ 30 | 115 | 55,7 % | 62,4 % | 38,3 % |
| **всего** | **372** | **54,8 %** | **57,8 %** | 44,8 % |

- **Формула сама обещает около 58 %, не 60.** В полосе 0,8–1,25 армия с меньшей численностью отыгрывает почти всё
  преимущество качества 10–20 пунктов: при качестве 60 против 50 и армиях 0,8 : 1 силы почти равны. Даже точная
  реализация формулы не дала бы 60 % на этих боях.
- **Реализация совпадает с формулой в пределах шума:** 54,8 % против обещанных 57,8 %, стандартная ошибка доли при 372
  боях — 2,6 пункта, отклонение −1,2 ошибки; по корзинам — от −1,5 до +1,6 ошибки.
- Мерило проверяет не исполнение модели, а то, насколько качество перевешивает численность. Это свойство формулы и
  авторских разрывов в качестве (стартовые значения 45–88), а не дефект. Решение — за владельцем.

# Ц4 стадия 2: исправленное мерило на отложенных сидах — стоп по спаду Ц6

57,8 %). Мерило возвращено к цели Ц4 и проверено на **отложенных сидах 100–129** — не на тех, по которым выводилось.

## 3. Арифметика для Ц7 (сиды 0–29 стадии 1, модель (а), без новых прогонов)

**Что это значит для механизма** (только арифметика, решение — за владельцем):
- Под полной угрозой бои проигрываются в 85–95 % случаев. При доле проигрыша q ожидаемое число боёв до первой серии
  длины K — (1 − q^K) / ((1 − q) · q^K): при q = 0,95 это 3,3 боя для K = 3, 5,8 для K = 5 и 10,1 для K = 8. Серия любой разумной длины набирается почти наверняка, и
  K решает прежде всего **когда**, а не **кто**.
- Бои сосредоточены в начале партии: медиана первой серии K = 3 — тики 17–20 (rome, milan, constantinople none). Частота
  боёв под полной угрозой — один бой примерно на 8 тиков в constantinople и на 25–35 тиков в rome и milan.
- **Варвары у армии Рима** при K = 3–5 гибли бы в 21–30 играх из 30, около тиков 17–28 (383–389 гг.) — это и есть пункт
  §9.2 «гибнут варвары». Рим не набирает серию ни разу.
- **Византия без игрока:** K = 3 — 24 из 30, медиана первой серии около тика 20 (1440); K = 5 — 17 из 30, около тика 30
  (1445). Это раньше 1450-х (тики 40–59). В сыгранных мирах серия набирается в 28–30 играх из 30.
- **milan:** Милан серию не набирает, но **папство** набирает её в 26–30 играх из 30 — механизм убил бы папство. Савойя —
  30 из 30.
