# Шаг 2: сравнение четырёх моделей на новых промптах

Решение владельца (2026-10-11): последние доступные версии DeepSeek, MiMo, GLM и Kimi на новых промптах тех же шести
партий. Промпты — после летописи мира (#264) и чистки окна событий (#265, #266), main 093cec1.

## Модели

Каталог провайдера nano-gpt (`/v1/models`), **2026-10-11**. Брались последние версии без вариантов `:thinking` и без
специализированных:

| семья | модель | примечание |
|---|---|---|
| DeepSeek | `deepseek/deepseek-v4.1-flash` | v4.1 есть только в варианте flash; последняя pro — `deepseek/deepseek-v4-pro-0813`, в сравнении не участвовала |
| MiMo | `xiaomi/mimo-v2.6-pro` | |
| GLM | `z-ai/glm-5.3` | `zai-org/glm-5` из замера памяти не последний, поэтому эталоном не участвует |
| Kimi | `moonshotai/kimi-k2.6` | `kimi-k2.7-code` — модель для кода |

## Как мерилось

- **Материал.** Шесть партий замера памяти и их окна: none — сиды 0, 9, 2; aggressive — сиды 0, 7, 9; по 10 хроник
  подряд. Всего 60 хроник на модель, 240 на все четыре.
- **Путь продуктовый**, тот же, что в замере: `chronicle_probe live`, модель подменяется переменной
  `CHRONICLE_MODEL`. Провайдер, ключ, тело запроса и `max_tokens` = 4000 — как в продукте.
- **Своя книга у каждой модели.** Готовая хроника ложится в книгу партии, поэтому стоп-лист строится из собственных
  текстов модели.
- **Перезапуск после ошибок 429.** Первый прогон шёл по 24 запроса одновременно и упёрся в лимит одновременных
  запросов аккаунта: 36 хроник не написались. Пропуск меняет книгу и стоп-лист следующих хроник, поэтому каждая
  партия с пропуском перезапущена целиком, по одному запросу на модель. В итоговом материале ошибок нет: 60 из 60 у
  каждой модели.
- **Оценка.**
  - Счётчики — `model_compare/eval.py` по выходу пробы.
  - Срабатывания сита о противоречиях дочитаны глазами.
  - Язык на чтение оценивает владелец по книгам партий `model_compare/<модель>/<мир>_s<сид>.md`: в каждой — факты
    движка и хроника на каждый тик.

### По моделям

- **DeepSeek v4.1-flash.** Единственная модель, прошедшая жёсткое условие, — ровно на границе: 1 хроника из 60
  («дыхание文艺复兴», aggressive сид 9, тик 32).
  - Ключей и чисел нет.
  - Слабое место — зачин: 20 из 60 хроник открываются датой («В год Господень 1477-й…») вопреки инструкции.
  - Противоречий фактам при чтении не найдено. Срабатывания сита ложные: союз против Милана описан верно, подчинение
    Сиены — как случившееся. Решения игрока упоминаются как прошлое («те, кто стоял за подстрекательством баронов в
    первые годы…»).
- **Kimi k2.6.** Лучшая по зачинам (7 с даты, 1 повтор), ключей и чисел нет. Жёсткое условие не прошла: 4 хроники с
  иероглифами внутри слов («Фе城管局ранте», «Союз Итали志刚诞»). Противоречия, найденные при чтении:
  - союз «с восьмидесятого года» вместо 1477-го (aggressive сид 0, тик 5);
  - «в тридцать девятом году» (тик 9);
  - «шестер counselorов» (тик 1).
- **MiMo v2.6-pro.** Выбывает.
  - 22 хроники с чужой письменностью.
  - В 8 хрониках текст распадается в кашу на смеси языков («Мол烃иони взываат Мантрот», «tiếp tục推кение»).
  - Одна хроника открывается рассуждением по-английски: «Let me write a proper Russian chronicle…».
  - 4 хроники с ключами движка, 6 с числами.
- **GLM-5.3.** Выбывает в продукте как есть: **35 из 60 ответов пустые.** Модель и без `:thinking` иногда уходит в
  рассуждение и тратит на него все 4000 токенов ответа — `finish_reason: length`, `content` пуст.
  - Воспроизведено на одном промпте: 2 пустых ответа из 6 (3 998 и 4 000 токенов рассуждения).
  - В продукте игрок получил бы пустую хронику.
  - Из 25 написанных — 4 с иероглифами.

## Что не мерилось

- Последняя pro-модель DeepSeek (`deepseek-v4-pro-0813`): по правилу «последняя версия» взят v4.1-flash.
- GLM-5.3 с выключенным рассуждением или большим `max_tokens`: это правка тела запроса в продукте, вне объёма замера.

## Дополнение (решение владельца): DeepSeek pro, GLM-5.3 без пустых ответов, Sonnet

Три прогона по тем же правилам: шесть партий, по 60 хроник, у каждой модели своя книга и стоп-лист.

- **`deepseek/deepseek-v4-pro-0813`** — последняя pro-версия DeepSeek, nano-gpt.
- **GLM-5.3 «с выключенным рассуждением»** — так невозможно.
  - Провайдер отклоняет все три способа (`reasoning.enabled=false`, `thinking.type=disabled`,
    `reasoning_effort=none`) с ответом «GLM 5.3 always thinks and does not support disabling reasoning».
  - Проверены на одном промпте, по 5 запросов: `reasoning_effort=low` — 2 пустых из 5, `minimal` — 5 из 5; бюджет
    ответа 16 000 — 0 из 5, но рассуждение доходит до 7–9 тыс. токенов.
  - Мерился ближайший рабочий вариант — **`max_tokens` = 16 000**. Для этого в `LlmConfig` добавлено необязательное
    поле `max_tokens`; без него продукт шлёт прежние 4000, сохранение настроек из интерфейса поле не стирает.
- **Sonnet через подписку Claude** — `claude-sonnet-5-5`. У nano-gpt Sonnet нет. Хроники писал `claude -p` (Claude Code
  CLI, безголовый режим, вход по подписке):
  - без инструментов, без сохранения сессии, из пустого каталога — без `AGENTS.md` и настроек проекта;
  - промпт поделён так же, как в продуктовом пути для Anthropic (`stream_narrative_anthropic`): системная часть — до
    «=== НАРРАТИВНЫЕ ИНСТРУКЦИИ ===», остальное — сообщение пользователя;
  - цепочка та же: `chronicle_probe step` строит промпт, хроника ложится в книгу, следующий промпт строится с её
    стоп-листом. Скрипты — `model_compare/sonnet/`.

  Отличие от продукта: продукт ходит в API Anthropic по ключу `sk-ant-…`, а не по подписке. Модель та же, путь
  вызова другой.

### По трём новым

- **Sonnet 5.5** — самый чистый вход и выход.
  - Ни одного иероглифа и ни одного латинского слова на 60 хроник, ключей и чисел нет.
  - Инструкцию о зачине держит: 4 зачина с даты, 1 повтор.
  - 4–6 абзацев во всех 60.
  - Противоречий при чтении не найдено. Все четыре срабатывания сита — верные утверждения: союз Венеции, Неаполя,
    Рима, Сицилии и Флоренции стоит против Милана.
  - Самые короткие хроники (медиана 2 939 знаков), в рамке требования.
- **DeepSeek v4-pro** — условие проходит: 0 хроник с чужой письменностью, 3 латинских слова на 60.
  - Противоречий при чтении не найдено. Срабатывание «Милан в союзе» на тике 1 верно: по фактам движка лига
    оборачивается против Милана позже.
  - Слабое место — зачин: 36 из 60 с даты или времени года («Лето клонилось к исходу…», «Лето Господне 1489-е…»).
- **GLM-5.3 с бюджетом 16 000** — пустых ответов нет, но условие не прошло: 6 хроник с иероглифами («вуалью公社»,
  «Феррара —这个小 кузница»). Цена — рассуждение до 9 тыс. токенов на хронику, прогон шёл втрое дольше DeepSeek.

**Итог по жёсткому условию:** прошли три — Sonnet 5.5 (0), DeepSeek v4-pro (0), DeepSeek v4.1-flash (1, на границе).
