# Казна и `economic_output` с удержанным доходом — A46, стадия 4

Только замер, правок контента нет. Вывод `src/bin/a46_eco_probe.rs` (фича `census`), режимы
`treasury` и `cf4`, 30 сидов × 300 тиков, все миры трёх сценариев. Разбор — `docs/TRIAGE.md`,
раздел «A46, стадия 4».

- **Казна по источникам:** формула казны разделена на доход (`economic_output × population ×
  0.001`) и содержание армии (`military_size × 0.8`) через приёмник частей формулы (только под
  фичей, арифметика не меняется); остальные записи в `treasury` — по источникам. «Прочее» у Рима —
  в основном структурная перезапись при расколе (`seat_split`), а не поток.
- **Контрфакты в памяти:** (в) отток, пропорциональный уровню (как в стадии 3); (г) = (в) с
  коэффициентом дохода, подобранным так, чтобы медиана суммарного дохода партии по сценарию
  совпала с базой (10 сидов, все миры: пропорциональный шаг от 0.001, затем шаг секущей); (д)
  модификаторы тегов по `economic_output` — уровень: прибавляются один раз при появлении тега,
  вычитаются при снятии, остальные метрики тегов не тронуты; (д′) = (д) с тем же подбором дохода.
